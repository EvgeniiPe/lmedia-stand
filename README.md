# lmedia-stand

Черновик лендинга LMedia (ru) и стенд его дизайн-системы — для просмотра.

- `index.html` — лендинг одной страницей, 11 блоков.
- `stand.html` — стенд: основы и компоненты (01), блоки 1–5 (02), блоки 6–11 (03).

Заглушки `[…]` — данные ещё не подтверждены. Страницы закрыты от индексации (`noindex`).
Источник — частный репозиторий; лендинг собирается из страниц стенда (`build_landing.py`), здесь руками не правится.
